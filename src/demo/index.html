Branchcut · version control for the edit, not the pixels

Two editors, one cut, and no more final_v3_actual (1).mp4

Branchcut versions the edit decision list: which piece of which file plays where. Each editor works on a branch. The diff says what changed in editor words. The merge combines both cuts by itself and asks only the questions a person must answer.

Everything on this page runs in your browser: the same TypeScript core as the API server, with an in-memory repository. Nothing is sent anywhere.
